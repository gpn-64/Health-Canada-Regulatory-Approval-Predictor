# data

- `raw/` — source brute, telle qu'extraite. Gitignored par défaut si volumineux ou sensible (voir [.gitignore](../.gitignore)).
- `processed/` — données nettoyées et transformées, prêtes pour le dashboard.
- `sample/` — échantillon anonymisé, toujours versionné, pour permettre une démo publique sans exposer de données réelles.
